## Subset-sum seminar exercise

This small exercise compares several algorithms for the subset-sum problem:

* brute force,
* dynamic programming, and
* meet in the middle.

The instance is stored in `data.txt`. The first line is the target sum and the
remaining lines are the available numbers. Lines beginning with `#` are comments.

Run the exercise with:

```sh
python3 main.py
```

You can test another instance by passing a different text file:

```sh
python3 main.py my_numbers.txt
```
